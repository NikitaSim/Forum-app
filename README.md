# Forum App

Приложение представляет собой консольную систему форума, построенную по принципу Reddit-подобного сервиса.

Пользователь может зарегистрироваться и войти в систему, после чего создавать и просматривать темы форума, публикации и комментарии, а также голосовать за публикации.

## Основная функциональность

- регистрация пользователей;
- авторизация пользователей;
- создание, просмотр и удаление пользователей;
- создание и просмотр тем форума;
- добавление тегов к темам;
- создание и удаление публикаций;
- поиск публикаций и тем;
- добавление и удаление комментариев;
- голосование за публикации;
- изменение голоса пользователя;
- подсчёт рейтинга публикаций;
- проверка существования пользователей, тем и публикаций;
- защита от повторного голосования;
- обработка некорректных входных данных;
- многопоточная проверка операции голосования;
- модульное тестирование бизнес-логики.

## Структура проекта

### `models`

Содержит основные модели предметной области:

- `User` — пользователь системы;
- `ForumThread` — тема форума;
- `Post` — публикация внутри темы;
- `Comment` — комментарий к публикации;
- `Vote` — голос пользователя за публикацию;
- `UserRole` — роли пользователей;
- `VoteType` — тип голоса (`UP` / `DOWN`).

Модели описывают данные и связи между объектами предметной области.

### `repository`

Содержит интерфейсы репозиториев, определяющие операции работы с данными.

Основные репозитории:

- `UserRepository`;
- `ThreadRepository`;
- `PostRepository`;
- `CommentRepository`;
- `VoteRepository`.

Интерфейсы репозиториев отделяют бизнес-логику от конкретного способа хранения данных.

### `service`

Содержит бизнес-логику приложения.

Основные сервисы:

- `UserService` — операции с пользователями;
- `AuthService` — регистрация и авторизация;
- `ForumThreadService` — работа с темами форума;
- `PostService` — работа с публикациями;
- `CommentService` — работа с комментариями;
- `VoteService` — работа с голосами и рейтингами.

Сервисы выполняют проверки входных данных, проверяют существование связанных объектов и обеспечивают выполнение бизнес-правил.

`VoteService` также содержит синхронизированные операции создания и изменения голосов. Это позволяет корректно обрабатывать одновременные запросы нескольких потоков и предотвращать создание нескольких голосов одного пользователя за одну публикацию.

### `ui`

Содержит консольный интерфейс приложения.

При запуске пользователь сначала может зарегистрироваться или войти в существующую учётную запись. После авторизации становятся доступны основные функции форума.

### `tests`

Содержит модульные тесты сервисного слоя.

Тестируется создание и удаление объектов, поиск, авторизация, комментарии, голосование, обработка ошибок и конкурентный доступ к операциям голосования.

Отдельный тест проверяет, что при одновременной попытке нескольких потоков проголосовать за одну публикацию создаётся только один голос.
